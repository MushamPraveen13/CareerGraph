# 🚀 CareerGraph

CareerGraph is a career-readiness platform designed to help students and fresh graduates plan, prepare, and track their career journey in one place.

## 🌟 Features

- 🔐 Login and Sign Up
- 🎯 Career selection
- 🗺️ Personalized career roadmap
- 📊 Skill tracker
- 🚀 Portfolio project tracker
- 🎤 Interview preparation
- 📄 Resume readiness checklist
- ✅ Job-ready checklist
- 📋 Job application tracker
- 📈 Career readiness dashboard
- 💾 Progress saved in the browser
- 📤 Progress export

## 🎯 Career Paths

CareerGraph currently includes:

- 📊 Data Analyst
- 💼 Business Analyst
- 📱 Digital Marketing

Each career provides relevant skills, roadmap steps, projects, and preparation resources.

## 📊 Dashboard

The dashboard helps users monitor:

- Overall career readiness
- Skills progress
- Roadmap progress
- Project progress
- Interview preparation
- Resume readiness
- Job readiness
- Job-search activity
- Recommended next action

## 🗺️ Data Analyst Roadmap

The Data Analyst roadmap includes:

1. Learn Excel
2. Learn SQL
3. Learn Power BI
4. Learn Python
5. Learn Data Visualization
6. Build Portfolio Projects
7. Prepare for Interviews
